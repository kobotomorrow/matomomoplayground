- ローカルPCよりだいぶ早い。これはCPUの性能差によるものと思われる
- 1024KBでL2キャッシュを超え、ランダムアクセス時間が増加した
- 4096KBまではL3キャッシュに収まるため、一段階小さなサイズとアクセス時間はあまり変わらない
- 8192KB以降はメモリアクセスが発生し、アクセス時間が増加した
- メモリアクセスの発生以降も、サイズに比例してアクセス時間が増加している
- TLBのミス
- プログラムのデータアクセス
  * ページテーブルを使って仮想アドレスを物理アドレスに変換
  * 物理アドレスを使ってメモリまたはキャッシュメモリにアクセス
- 1つ目のマッピングをCPU上にキャッシュしておくのがTLB
- ページ単位でマッピングを管理しているため、シーケンシャルアクセスの場合は空間局所性が高く、TLBのミスが少ない
- 一方でランダムアクセスの場合は空間局所性が低く、TLBのミスが多くなるため、アクセス時間が増加する
- つまり、ランダムアクセスではTLBミスとキャッシュメモリのミスが発生しやすく、アクセス時間が増加する傾向がある
